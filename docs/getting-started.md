## Create the template variable

Create a new template variable and select **File+** as input type in the
*Input Options* tab and as output type in the *Output Options* tab. Assign the
template variable to the templates and select a media source in the *Media
Sources* tab, if the files are not stored in the default media source.

## Upload a file

In the resource, the template variable shows a field with three buttons:

* **Clear**: Remove the file from the template variable. The file is not deleted.
* **Upload**: Upload a file from your computer into the upload path of the media source.
* **Browse**: Select a file in the media browser.

The selected file is shown below the field with an icon of its file type and
can be opened with a click.
