# File+

File+ is an advanced file upload template variable for MODX. A file can be
uploaded directly in the template variable or selected in the media browser. The
allowed file types and the upload path can be configured for each template
variable.

### Requirements

* MODX Revolution 2.8+
* PHP 8.2+

### Features

* Upload a file or select it in the media browser, integrated with the MODX Manager interface.
* Restrict the allowed file types for each template variable.
* Upload path with date, user, resource and template variable placeholders.
* Optional title and description fields for the file.
* Use a chunk as output mask and fill placeholders with the url, the filename,
  the file size, the title, the description etc. of the file.
