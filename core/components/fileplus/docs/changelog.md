# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-14

### Added

- Initial release, based on the upload and media browser field of Image+ 3.0
- File upload and media browser selection in the template variable
- Allowed file types and upload path input options/system settings
- Optional title and description fields
- Output chunk with url, file, filename, extension, size, title and description placeholders
- FilePlus snippet as alternative to the template variable output
- FilePlus.ColumnRenderer for MIGX and Collections grids
